# Changelog

## v0.1.0

First release.

- "Timeline Graph" profiler panel: one box per service, grouped by feature, one arrow per caller → callee with the methods called.
- Database, HTTP, LDAP and Twig calls shown as their own boxes.
- Failing paths highlighted in red.
- Replay player with step forward / back and breakpoints.
- Configuration: `include`, `exclude`, `group_depth`, `max_calls`.
